# منظومة الأميرة ERP V2 لإدارة المخزون والمبيعات
## شركة الأميرة للتوريدات العامة والتجارة (Al-Amira ERP V2)

نظام سحابي مؤسسي متكامل مبني بالكامل بأحدث تقنيات الويب الحديثة (**React 18 + Vite + TypeScript + TailwindCSS + Supabase / PostgreSQL**)، تم تطويره ليحل محل الإصدار V1 وفق أعلى معايير الأمان المالي والرقابي وتجربة المستخدم السلسة باللغة العربية (RTL).

---

## 1. الهيكلية التقنية للمشروع
- **تطبيق الواجهة الأمامية (V2 Frontend):** داخل المجلد `alamira-v2/`
- **قواعد البيانات والترقيات السحابية (Supabase SQL Migrations):** داخل المجلد `supabase/`
  - الملف الأساسي للترقية والتشغيل: `supabase/migration_v2_real_backend.sql`
- **إعدادات النشر السحابي (Vercel):** مهيأ تلقائياً في `vercel.json` و `alamira-v2/vercel.json`

---

## 2. الميزات والمسارات التشغيلية الرئيسية
1. **المصادقة والأدوار المؤسسية (RBAC):**
   - فصل كامل بين دور الإدارة العليا (`ADMIN`) ومسؤول المبيعات (`SALES_OPERATOR`).
   - حجب أسعار الشراء، نسب الأرباح، ورصيد المخزن الفعلي عن مسؤولي المبيعات على مستوى الواجهة وقاعدة البيانات (`Column-Level Security`).
2. **إدارة الأصناف والمخزون:**
   - دعم كامل للأسعار والفئات والوحدات.
   - تمكين مسؤول المبيعات من إدخال الرصيد الأولي ورؤيته أثناء الإنشاء وحفظه في القاعدة، ثم حجبه تلقائياً بعد الحفظ.
3. **دورة فواتير المبيعات الذرية:**
   - اعتماد وإلغاء الفواتير عبر إجراءات ذرية سحابية (`Atomic RPCs`) تمنع الرصيد السالب وقفل السجلات لمنع التضارب (`FOR UPDATE`).
   - قالب طباعة رسمي احترافي A4 مع تصدير مباشر لصورة PNG عالية الجودة.
4. **سجل الرقابة والنشاط التدقيقي:**
   - سجل حركات تدقيقي غير قابل للتعديل أو الحذف (`Append-Only`) مع ضبط التوقيت الرسمي لقنا ومصر `Africa/Cairo`.
5. **لوحات تحكم ذكية مخصصة:**
   - لوحة إدارية شاملة للمدير، ولوحة مبيعات مركزة من 3 أقسام فقط لمسؤول المبيعات.

## 3. تعليمات التطوير والتشغيل المحلي
```bash
# الانتقال لمجلد التطبيق
cd alamira-v2

# تثبيت الحزم
npm install

# تشغيل بيئة التطوير المحلية
npm run dev

# تشغيل حزمة الاختبارات الآلية (213 اختباراً)
npm test

# فحص الأنواع البرمجية والترجمة
npx tsc -b
npm run lint
npm run build
```
