# مسار الأصول والشعار الرسمي — شركة الأميرة للتوريدات العامة والتجارة

النظام مجهز بالكامل لقراءة وعرض الشعار الرسمي للشركة من هذا المسار:
- **الملف الموصى به:** `logo.png` (أو `logo.svg`)
- **الأبعاد:** يفضل صورة عالية الدقة بخلفية شفافة (PNG أو SVG) بأبعاد طولية/عرضية طبيعية.
- **خصائص العرض في النظام:**
  - يتم عرض الشعار بألوانه الأصلية ونسبه الهندسية الدقيقة 100% دون أي تمديد أو اقتطاع (`object-fit: contain`).
  - معالجة عالية التباين على شاشات Retina وشاشات الهواتف الحديثة.
  - في حال عدم إيداع الملف، يوفر النظام شارة هوية بديلة راقية تضمن سلامة المظهر دون أي أيقونة صورة مكسورة.
